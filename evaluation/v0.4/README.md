# GaiaLab Naija Assistant v0.4 Evaluation

This fixed benchmark compares v0.3 and v0.4.

- 50 prompts
- 10 categories
- Fixed prompt IDs
- Human review

Score each response from 1 to 5 for instruction following, factual consistency, tone, clarity, and safety. Also record hallucination, pass/fail, and reviewer notes.

Do not use benchmark prompts as training examples.
